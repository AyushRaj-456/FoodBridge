# Performance Testing

Test geospatial feed, listing detail, claim contention, admin queue, bounded analytics and in-app notification inbox. Measure page load, interaction latency, Firestore reads/writes, document size, listener count, network transfer and memory. Verify no duplicate claims and no unbounded queries. Test map tile failure and quota-exceeded states. Record environment, dataset and commands. Do not introduce a paid load-testing SaaS; use local open-source tools and synthetic data.
