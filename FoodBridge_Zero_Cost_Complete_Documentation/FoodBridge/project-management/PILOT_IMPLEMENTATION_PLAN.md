# Pilot Implementation Plan

Objective: validate whether the workflow reduces avoidable surplus and improves timely traceable redistribution without compromising safety/privacy.

Before pilot: institution approval; qualified food-safety SOP; permitted categories; verified recipient cohort; collection windows; staff training; baseline method; incident contacts; synthetic end-to-end test.

Suggested 1–2 weeks: days 1–3 baseline only; days 4–7 controlled listing/collection; second week repeat and refine if approved. Daily: record meal data; reconfirm condition/quantity before publish; recipient accepts only if able to collect; both confirm handover; operations lead reviews exceptions.

Stop conditions: suspected safety incident, unclear route, unauthorised recipient, repeated failed handover, data exposure or missing supervision. Compare waste per person served while noting menu/attendance differences. Small uncontrolled pilot cannot prove causality.
