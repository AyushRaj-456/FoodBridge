# User Journeys

## Donor

Email sign-in → select approved donor organisation → create listing → enter food, quantity/unit, preparation/consume-by times, handling declaration, allergens, pickup window and location → preview → publish → coordinate direct collection → confirm handover → view history. No photo upload in MVP. Errors include invalid time, expired listing, unavailable quota, suspension and recipient cancellation.

## NGO recipient

Email sign-in → submit organisation profile and contact details → await manual offline document review and admin approval → configure service area/capacity → browse eligible listings in map or text list → review approximate location and details → claim → view exact pickup details → collect → confirm handover → optionally record beneficiary count without identifiable images.

## Cattle farm

Apply with owner/farm details → manual review → remain disabled for food claims until qualified animal-feed suitability criteria and written SOP are approved → only then receive eligible listings. Human-ineligible food is never automatically considered animal-safe.

## Compost/biogas facility

Apply with facility details, accepted-material list and capacity → manual review → remain disabled until facility-specific acceptance SOP and contamination rules are approved → accept only compatible material.

## Mess operator

Email sign-in → select assigned mess → enter prepared, served and leftover quantities with meal, dish, date and people served → review daily summaries and historical trends → use advisory forecast only after sufficient data.

## Administrator

Admin account is provisioned manually in Firebase Console → sign in → review pending organisations using offline checklist → approve/reject with reason → moderate listings/reports → suspend accounts if necessary → inspect audit records and manually monitor quotas. Admin does not upload or store identity scans in FoodBridge.
