# Task Breakdown

1. Project setup: React/Vite/JavaScript, npm lockfile, CSS tokens, lint/tests.
2. Firebase: Spark project, Auth email/password, Firestore, rules, indexes, emulators.
3. Security: deny-by-default rules, manual admin provisioning, role/membership tests.
4. Organisation onboarding: donor/NGO/farm/facility form and offline review checklist.
5. Listings: lifecycle, units, dates, declarations and expiry-at-interaction.
6. Location: browser permission, manual pin, Leaflet/OSM attribution, geohash + Haversine.
7. Matching: eligible feed, approximate location, radius expansion.
8. Claims: Firestore transaction, concurrency tests, handover confirmations.
9. Mess analytics: prepared/served/leftover records, descriptive dashboard.
10. Notifications: in-app Firestore inbox only.
11. Impact: measured quantities, provenance and estimate labels.
12. Deployment: Firebase Hosting Spark, Firestore rules/indexes only.
13. Pilot: permissions, SOP, manual verification, training, usage and quota review.

Deferred: phone OTP, shared media/document upload, SMS/WhatsApp, background push, scheduled worker, Cloud Functions, AI APIs, paid routing/geocoding, delivery helper dispatch.
