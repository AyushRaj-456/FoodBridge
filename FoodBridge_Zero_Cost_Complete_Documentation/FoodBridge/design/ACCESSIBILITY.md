# Accessibility

Target WCAG 2.2 AA for core flows. Use semantic landmarks/headings/buttons; full keyboard operation and visible focus; logical focus order and restoration; associated labels/errors; announced status updates; tested contrast; never colour alone; reduced-motion support; text alternatives for charts; zoom/reflow; screen-reader testing and manual review. Automated scans do not replace manual accessibility testing.
