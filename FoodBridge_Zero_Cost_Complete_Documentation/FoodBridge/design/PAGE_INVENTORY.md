# Page Inventory

Shared: landing/about, email sign-in, registration, password reset, profile, organisation switcher, in-app notifications, help, privacy and terms.

Donor: donor dashboard, create/edit listing, listing preview, active/history listings, claim detail, handover confirmation.

Recipient: recipient dashboard, eligible feed/list, optional map, listing detail, claim confirmation, pickup/handover, donation history.

Mess operator: meal record entry, daily records, dish trends and data completeness.

Admin: pending organisation applications, manual verification checklist, listing moderation, reports, account/organisation status, audit view and quota checklist.

No OTP screen, shared photo upload, document upload, SMS settings, WhatsApp integration or delivery dispatch screen in MVP.
