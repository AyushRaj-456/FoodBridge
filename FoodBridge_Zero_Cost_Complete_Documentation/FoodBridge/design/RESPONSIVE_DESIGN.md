# Responsive Design

Breakpoints: 360 px mobile baseline, 768 tablet, 1024 compact desktop, 1280 wide desktop. At 360 px, core flows must not require horizontal scrolling. Sidebar becomes compact top/bottom navigation. Forms are single-column on mobile. Touch targets 44×44 CSS px where practical. Sticky actions must not obscure fields or keyboard. No responsive image derivatives are needed in MVP because shared media uploads are deferred. Test 320/360/390/768/1024/1440 widths and 200% zoom.
