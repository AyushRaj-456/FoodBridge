# Component Library

## Foundations

Use semantic HTML and CSS variables. Components must expose keyboard focus, accessible names, error association and loading/disabled states. Use open-source icon assets or inline SVG; no paid component kit.

## Core components

- Navigation: responsive sidebar/top navigation and role switcher.
- Buttons: primary, secondary, quiet, destructive; consistent sizes and focus rings.
- Forms: text, textarea, select, date/time, quantity+unit, checkbox, radio, location picker and manual address fields. No file-upload control in MVP.
- Data: listing rows/cards, status badges, metric summaries, paginated tables, empty states.
- Feedback: inline validation, toast, confirmation dialog, permission prompt, quota-exceeded banner, offline banner.
- Map: Leaflet map with visible OSM attribution and list fallback.
- Workflow: listing status timeline, claim state, handover confirmation panel.
- Analytics: accessible charts with textual summaries and date filters.

Avoid giant rounded-card grids, decorative gradients, emoji navigation and unnecessary animation. Do not create upload progress, OTP, SMS or delivery-dispatch components for MVP.
