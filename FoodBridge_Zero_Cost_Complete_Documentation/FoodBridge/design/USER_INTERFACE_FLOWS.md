# User Interface Flows

## Publish listing

Donor dashboard → new listing → food details → handling/time and allergens → pickup location → declaration → preview → publish → status/history. No photo upload step.

## Discover and claim

Recipient feed → filters/map or text list → listing detail with approximate location → confirm eligibility/quantity → claim transaction → success or conflict/expiry explanation → exact pickup details.

## Handover

Claim detail → donor and recipient independently confirm transfer → actual quantity and unit → completed or disputed. Corrections are audited.

## Verification

Organisation application → submit structured details → status pending → admin manually checks supporting documents offline → approve/reject with reason → applicant sees status. No document upload.

## Mess analytics

Select date/meal → enter prepared/served/leftover quantities → save → dashboard trends and completeness → forecast only when sufficient historical data exists.

## Map fallback

If location permission is denied, use manual pin/address. If OSM tiles fail, show address and Haversine distance in a list. Do not promise road route or ETA.
